# Blink Count

A no-dependency, just-for-fun daily blink estimate. Open `index.html` in a browser to use it.

The estimate starts with 15.5 blinks per awake minute, applies a modest regional climate multiplier, adds 4% for each hour of sleep below eight, and adds small uplifts during computer and sports hours. Computer and sports hours are counted as separate parts of the waking day, so the estimate rejects schedules that exceed the available hours.

The regional values are broad illustrative approximations, not live weather data or medical guidance. Individual blink rates vary substantially.
